# Adrian Doria — Portfólio

portfólio. Criado com a SiteFactory.

## Rodar localmente
```
npm install
npm run dev
```

Build de produção: `npm run build`

## Trabalhar com Claude Code
Este projeto usa o plugin `sf` da SiteFactory (mais Impeccable e Playwright), habilitados em `.claude/settings.json`. Abra a pasta no Claude Code e diga "continue de onde paramos". Estado e decisões ficam em `docs/`.
